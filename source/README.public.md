# 適ケアくん

「適切なケアマネジメント手法」を使って、ケアマネジャーが事例を整理し、次に何を確認すればいいかを考えるためのツールです。

**→ [使ってみる](https://kat-t00.github.io/tekicare-app/)**

> 独立した非公式の試作版です。日本総合研究所・厚生労働省の公式アプリではありません。

## できること

- 事例の記録文を入力すると、課題分析標準項目23項目に振り分け
- 公式の支援項目(基本ケア44・疾患別163)と照らし合わせて確認
- 「誰に・何を・なぜ確認するか」を整理して表示
- 研修モードで自分の着眼点を振り返る
- 端末内で動くAIによる追加の確認候補(任意、外部に送信されません)
- スマホ対応、ライト/ダークモード

## 使い方

上のリンクを開いて、事例(架空のサンプルもあります)を入力し「分析する」を押すだけです。入力した内容は外部のサーバーに送信されません。
